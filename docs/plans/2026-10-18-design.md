# TED_pre_master：设计与验收

## 目标

制作可公开安装的演讲写作技能，研究 TED 的观点组织、理解次序、故事与证据衔接及口头表达。技能应支持中文课堂汇报、技术解释、研究分享和既有稿件修订；质量依据为事实、理解与口头使用效果。

公开仓库名与显示名为 `TED_pre_master`，技能标识使用兼容 Codex 命名规则的 `ted-pre-master`。仓库独立于课程资料，公开内容使用原创示例和匿名合成任务。

## 方案选择

考虑三种方案：固定段落模板便于快速起稿；文风编辑器能改善既有句子；基于听众、证据和时间预算的写作流程覆盖完整演讲任务。采用第三种，并提供小规模编辑入口。篇章结构随解释、论证、真实经历或多主题分享的任务变化。

## 技能设计

入口说明保留关键决策和最短执行路线。研究依据、结构选择、中文口语编辑和排练方法各自独立，按任务读取。机械检查工具提供字符、舞台提示和用户约束的观察值，不输出自动演讲质量分数。

写稿前识别听众已有知识、主题、主张及依据、必须覆盖的内容、总时长与语气。已有资料足够时直接推进；关键证据缺失时先处理可写部分，再提出具体补充项。核心问题的答案应及时出现，信息递进用于帮助理解。

先写完整可说正文，再执行事实反查和口语修订。用具体推理桥连接相邻部分，保护单位、条件、比较对象、来源归属及判断强度。故事采用真实资料或明确标识的假设情景。用户指定的行文约束优先。

## 研究与实测

官方指导和演讲文本分别登记来源，区分官方建议、样本观察和本项目的编辑判断。样本覆盖解释型、数据展示型、经历叙事型等形式，记录适用边界。引用使用链接与简短必要摘录，研究文件采用原创分析。

冻结多领域任务后开展独立生成与审阅，检查事实与范围、问题递进、首次出现概念的解释、自然口语、语气及时间安排。保存实际输出、评价依据和修订记录。静态校验仅证明包结构与工具行为。

课程实测在本地课程目录保存：15 分钟同时覆盖抛硬币和 Wald–Wilson；硬币部分解释四种方法的选择，详讲四位窗口、重叠依赖、统计量、模拟参照及校正后结果。身份、学号、老师通知及原始作业图像留在本地课程资料中。

## 发布验收

- 技能入口、路由和支持文件完整，命名与元数据校验通过。
- 官方来源可定位，研究结论与来源支持范围对应。
- 真实使用输出接受独立评阅，问题有修订或明确的保留说明。
- 课堂实测的数据与当前计算结果一致，时间标注区分估计和实测。
- 公开文件经过路径、凭据和身份信息检查。
- GitHub 仓库公开可访问，远端提交与本地一致，CI 对该提交通过。
- 发布包可下载，散列与本地包一致；本机技能安装与发布版本一致。
