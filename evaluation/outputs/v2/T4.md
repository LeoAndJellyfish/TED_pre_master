# 两个年份，先对齐两件事

## 讲稿正文

### 00:00—01:15｜先核对两条日期各指什么（计划）

我先去看档案，也去听老人怎么讲。

档案记录这所学校的行政迁址日期是1953年9月。一位2018年的受访者回忆，自己于1954年开始到新校址上课。两个年份相差一年，读到这里，很容易先追问：哪一个时间准确？

不过，核对年份之前，先得核对两条材料各自在说什么。

档案说的是学校的行政迁址。受访者说的是自己开始到新校址上课。两条材料分别记录学校的行政事项和个人的上学经历，回答的问题不同。

[停顿 3秒]

两件事有可能先后发生。要判断其中的关系，一个关键细节是：受访者当年是否立即转学？案例对此尚无记录。核查个人回忆，应围绕个人开始到校这件事寻找依据。

### 01:15—01:45｜后续查证围绕个人到校时间（计划）

档案已经提供一个明确日期。这个日期对研究很有用，但迁址过程还涉及各项安排如何发生。研究若要继续，可以寻找与学生到校有关的记录，核对受访者的入学、转学或就读时间。这里说的是后续查证方向，案例里尚未提供这些资料。

### 01:45—03:00｜路程回忆对应两类研究问题（计划）

另一段口述提到“离家更远了”。讲述者回忆上学路程时，将新校址与更远的上学路联系在一起。这句话的用途，取决于研究关心什么。

如果研究关心实际距离，现有案例尚未核查住家位置、距离和步行路线。距离增加多少、步行路程是否增加，仍处在待查状态。若后续取得相应地点和路线资料，就可以检查这段回忆中的空间关系。

如果研究关心讲述者如何记忆上学经历，这句话已经提供了材料。它说明，在这段口述中，路程变化进入了讲述。研究可以分析它与迁址、上学这两件事的联系，并保留这句话的个人归属。

[停顿 3秒]

### 03:00—04:00｜说明现有材料的支持范围（计划）

由一个人的这句话，继续讨论“整个社区的生活改变了”，中间还有很大一段范围。这段口述提供的是个人的上学回忆。要研究整个社区，需要相应范围的材料，涉及哪些人、哪些活动、在什么时间发生了哪些变化，都应有记录支持。

档案提供行政迁址日期，访谈提供个人到校时间线与路程记忆。研究应分别说明这些材料回答哪个问题，以及哪些细节仍待核查。

认真对待一份记忆，可以从这里开始：写清它谈的是哪件事，保存它原有的说法，并说明现有材料支持到哪一步。

## 附录：实质修改说明

3. 保留档案对行政迁址日期的依据作用，并围绕个人就读时间提出具体查证方向；这些记录均明确为拟寻找的资料。
4. 区分实际距离与回忆中的路程体验，明确距离及步行路线的待核查状态，保留口述材料对记忆研究的用途。
5. 收窄“整个社区生活改变”的结论，将现有材料的支持范围落实到个人上学经历。
