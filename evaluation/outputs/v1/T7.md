# 翻译时，什么时候可以离开字面？

## 讲稿正文

“最后一缕光停在河面上。”

“河面留住了黄昏。”

这两个句子描写的画面很接近，读起来却各有重心。前一句先出现光，后一句先出现河面。我们今天讨论翻译的自由，就从这点变化开始。

先说明材料的身份：这是一组原创翻译练习，未指向实际出版作品。我们手边有一句英文和两种译法，没有全书语境。

原句是：The last light rested on the river。

[停顿 3秒]

我的判断是：翻译可以离开逐字对应，但每一处改动都应当有句内线索或语境依据，并且值得它所带来的意义变化。就目前这一句，译法A的依据更充分；译法B提供了有吸引力的读法，也提出了更多需要语境回答的问题。

先看A：“最后一缕光停在河面上。”

它保留了原句的基本安排。读者先看见“光”，再注意到光的停留，最后落到河面这个位置。英文中的 light 是主语，rested 写它的状态，on the river 写这个状态发生的地方。A沿着这个顺序，引导读者看见一处安静的光景。

但A也作了选择。英文中的 light 到中文里多了“一缕”。“一缕”给光加上了一种比较细、可以辨认的形态。“河面”也比“河”更明确地指出光停留的位置。这些处理使中文的画面更清楚，同时缩小了读者对光形和位置的想象范围。

“停”保留了静止的感觉。原句的 rested 还可能带出安歇、轻轻停留的意味；中文“停”比较简洁，声音也较干净。A接近原句，依然经过了语义和声音上的取舍。

再看B：“河面留住了黄昏。”

句子的起点换成河面。原来是光停留在河上，现在是河面做出了“留住”这个动作。河面仿佛具有了挽留的能力，画面里的主动性也随之增加。

变化还在宾语。B没有直接写光，改写为“黄昏”。原句的“最后的光”可以引起日光将尽的联想，B沿着这个线索，明确给出了时间和气氛。读者听到的是一整个黄昏在河面延续，视野比一缕光更宽。

与此同时，“最后”的限定在B里淡了。“留住”还增加了某种即将逝去、受到挽留的感觉。原句中有停留，B又写出了挽留。两种动作相邻，但各自承载的情绪有差别。

[停顿 3秒]

现在再听一次：

“最后一缕光停在河面上。”

[停顿 2秒]

“河面留住了黄昏。”

A从“最后一缕光”开始，声音有一段较长的铺陈，到“河面上”停住。B的字数更少，“留住”处于中间，后面的“黄昏”承担了收尾。这样的读法容易突出B的凝练和余韵。具体效果仍与朗读者的重音、停连有关；刚才这一遍，是两种句子各自可以采用的读法。

喜欢A的人，可能更看重光作为句子中心，也更看重“最后”所留下的时间边界。喜欢B的人，可能更看重中文里的简洁，以及河面与黄昏之间的牵连。两种偏好都有可说明的作品细节。

要继续判断B是否合适，语境就有用了。例如，前文若已明确处于黄昏，“黄昏”这个词的依据会更强；若上下文持续细写光线，省去“光”就可能割断原有的描写线索。这两种情况是假设的判断条件，现有材料尚未提供答案。

语境还可能帮助我们判断“留住”的情绪。如果作品反复借河流写对时间的留恋，B会获得呼应；如果这句话所在段落一直平静地记录眼前景物，B增加的主动性就更显眼。这里仍是在说明需要什么语境，未对一部未提供的作品作推断。

回到最初的问题：什么时候可以离开字面？

就这组练习而言，自由的分量落在具体的词上：保留“光”还是写成“黄昏”，描写“停留”还是增加“挽留”。A较完整地保存了句内关系，B以更凝练的声音扩大了意象，也增加了情绪。只有这一句时，我倾向于A；B的文学效果值得讨论，它与原作的贴合程度，取决于那些尚未出现的语境。
