# 判读要点

这是一道独立原创的中文口述稿修订任务，领域为博物馆公众讲解与展签阅读。场景、数据及叙述均为合成材料。此文件供判读使用，内容不应进入首次生成时的用户输入。

## 核心观察

检查交付是否为一篇完整、可直接讲述的正文，以及最多两句话的附注。正文应有连续的段落推进；新稿仅删除“首先”“其次”、仅替换词语、只交修改意见，均不足以完成整段修订。

全文应围绕观众的具体问题展开：五升米是否等于五公斤米。解释次序应能辨认出容积与质量的区别、同容积材料比较、观众如何进入展签、局部观察能支持什么判断。允许为口述自然调整段落位置，也允许合并步骤。重点在关系连贯，逐项复刻旧稿的路标无需奖励。

“人站在展柜前，眼睛未必已经走进展览。”须原样自然出现一次。检查它在上下文中的作用，孤立保留或集中放在附注均应记录为问题。

## 必核事实

- 五升指经过校准的内部容量，木斗为教学复制品。任何真实年代、来源、馆名均属新增事实。
- 升与公斤分别计量容积和质量；相同容积的不同材料可有不同质量。两次演示使用同一木斗、同一刻线，干燥材料刮平且不压实，比较需保持装法一致。
- 短粒米3.9公斤、红豆4.2公斤，各测一次。保留批次与装法范围；将这两个数值写成所有米或所有红豆的固定换算关系，应记录为实质事实错误。
- 原展签186字；新版132字，入口32字、细读100字。新版同时改变文字总量、信息层次和叙述顺序。
- 观察覆盖连续两个周日下午、8个半小时的时段；两版预排次序轮换，分组为非随机安排。每段按入厅顺序选前12名愿意回答的成年观众；每版4段、48人，总计96人。成人带孩子的合成开场场景与样本选择规则应保持区分。
- 超过20秒的长停留：原版18/48，新版29/48。计时边界是进入展柜正前方至移开脚步。停留数量与逐字阅读、完整读完的关系须有恰当范围。
- 有效解释：原版14/48，新版25/48。判定同时要求区分两类计量，并指出质量与材料有关。问题与判定标准须保持一致。
- 有效解释来自离开展柜后的一次提问，长期记忆属于后续检验范围。
- 新版对应的两项人数更高。归因至某一单独调整、扩展到其他展柜或所有观众，以及长期记忆结论，均超出材料范围。正文应以自然的口述句群容纳这些边界，避免附加一长段脱离主线的免责声明。

## 真实性与口述质量

正文应自然交代合成教学案例的性质。根据材料叙述可使用“我们看这个案例”等讲者组织语；“我当时接待他”“我们馆真实测试过”等亲历声称构成新增经历。原材料中的成年观众与孩子可以保留为合成场景，增加人物姓名、心理、动作、对话或结果时应核对其来源。

语气适合新人培训，计量术语应经具体例子获得解释。新稿可保留必要的简短路标，关键是减少连续编号、重复宣布结构，以及多次复述同一个结论。保留一句有个人语感的话应与其余段落的声线相容。

时长按正常中文讲述与合理停顿估计。正文长度与5—6分钟应大致匹配，附注中的时长只能视为估计。避免通过明显快读、无依据的“实测”时长或大段舞台说明满足要求。

## 建议记录方式

分别记录完整交付、整段改写、事实准确、范围与归因、必留句、观众问题及递进、口述自然度。实质错误优先于措辞偏好。事实包中的条件和数据可以口语化表达，也可以整合在同一句中；省略后造成读者误判时，应指出具体遗漏。此任务无唯一措辞或标准答案。
