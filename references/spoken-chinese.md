# 中文口语：声线、句群与听众负荷

这里的规则为本项目的编辑判断。相关 TED 官方指导、英中字幕样本及一条事实更正见 [研究依据](ted-evidence.md)。

## 先确定谁在说话

简记讲者身份、听众关系、正式程度、常用称呼、术语习惯和已有经历。输入含录音或写作样本时提取稳定用法；无样本时采用清楚、克制的现场解释语体，后续由讲者试读调整。

“我比较了两组记录”可以对应用户真实完成的分析。“那天晚上我突然明白了”需要真实经历。缺少个人故事时，从材料、问题或可复现演示进入。对题目的兴趣可以来自问题本身。

课堂汇报中的“大家看这一列”具有明确功能。网络梗、刻意自嘲、语气词、残句与错别字均按作者声线判断，避免为了模拟人类写作而添加。

## 每句提供可追踪的关系

检查谁、什么对象、在哪个条件下、做什么或发生什么、结果如何。用数、比较、抽样、模拟、排序、检查、估计等具体动词表达实际动作。术语需要区分概念时保留，并在第一次出现处解释它回答的问题。

数字需要对象、单位和比较基准。多个对象、时段和指标同时出现时，分句核对配对关系。口语可以省去书面标签，仍要保留论证所需的条件与限定。

“这个结果”“这种情况”“它”应有唯一清楚的先行对象。由局部转入总体、由观察转入解释、由结果转入建议时，重新写明对象。重复核心名词通常比连续更换近义词更易跟随。

## 句群负责推进

写出每段实际回答的问题，检查后一段增加了什么：观察维度、机制、检验或判断修正。介绍多个方法时说明各自读取的信息、依赖或互补关系。

路标用于认知跨度。更换主题、证据类型或观察层级时，一句短提示能帮助定位；连续讨论同一对象时直接续写。暂时遮住“接下来”“值得注意”“因此”等词，连读句群：关系仍清楚时删除空转提示，关系缺失时补解释。

具体的推理桥比流程播报更有作用。例如“次数接近一半之后，接下来检查顺序”说明了新步骤所回答的问题。用户禁止设问时，采用陈述式连接。

## 节奏依内容变化

首次介绍术语、新坐标系或多组数字时降低密度。先定位对象，再呈现影响判断的量，然后解释其作用。轻内容可以有较完整的语流；句子长度依能否顺畅说完和一次听懂决定。

笑点需要共同认识、真实材料及与论点的关系。停顿用于看图、形成预期、心算或消化判断。每处舞台动作应有明确任务，现场反应采用可继续讲述的预案。

完整连读两分钟，标出讲者平时不会说、需要临时翻译或难以一口气读完的地方；按这些具体问题编辑。再请独立读者复述比较对象、发现和判断理由。

## “AI 味”的审查单位

句群中的重复评价、虚设对立、空转过渡、整齐却无新信息的排比和不合身份的语气值得处理。限定语、必要对照与清楚的并列关系依其作用保留。通用词表用于定位，验收依据为命题、证据、声线和听众理解。

用户明确指定的禁句属于当前稿件约束。机械检查报告命中位置，编辑仍需重写完整句群。检测器分数和“人工写作概率”均不作为本技能的质量证据。

## 原创改写示例

下表采用构造条件，数值用于演示。实际稿件的数值来自当前资料。

| 问题 | 修订前 | 修订后 |
|---|---|---|
| 抽象开场 | 今天围绕硬币序列真实性判别展开系统汇报。 | 今天讨论一串正反面记录怎样接受随机性检查。 |
| 名词堆积 | 对正面出现频率这一指标进行了统计分析。 | 先数正面：100次里出现52次，占52%。 |
| 无比较对象 | 52%体现出较好的均衡性。 | 正面占52%，正反面的总数接近。 |
| 更换方法缺理由 | 随后引入顺序维度以提升全面性。 | 正反面的总数接近。接着检查它们出现的顺序。 |
| 差异只剩标签 | 两组排列形态存在差异。 | 两串各有50个正面、50个反面。一串正反交替，另一串先出现50个正面，再出现50个反面。 |
| 概念缺操作 | 使用蒙特卡洛模拟估计连续段的尾部概率。 | 假设每次抛掷独立、正反面机会各一半。电脑重复生成100次抛掷的记录，统计最长连续段达到10次或以上的比例。这个过程叫蒙特卡洛模拟。 |
| 数值缺条件 | 当前统计量的尾部概率为0.03。 | 在独立公平抛掷模型下，当前统计量达到观察值或更极端取值的概率是3%。 |
| 章节播报 | 接下来进入置信区间构造方法比较。 | 前面按给定的公平模型检查记录。现在根据观察到的比例，估计总体比例的范围。 |
| 读图评价空泛 | 图中直观体现出明显差异。 | 看两条曲线：它们对应两种方法，在两端相隔较远，中间较接近。 |
| 重复强调 | 顺序信息具有重要意义，值得充分重视。 | 排列顺序也提供了判断依据。 |
| 抽象收尾 | 分析深化了认识并提供了有益启示。 | 正面次数描述总量，连续段长度描述顺序。判断时逐项说明这两种依据。 |

改完逐项反查数字、单位、比较方向、条件、作者归属和判断强度。正文中的语气与材料实际支持的结论对应。
